# v2.0.0 Release Checklist

## Préparé par EF10

- version v2.0.0 ; métadonnées ; façade stable ; contrat compilable ;
  garde permanente ; changelog ; notes ; documentation de portée ; build ;
  audit d'axiomes ; arbre propre.

## À effectuer manuellement

- pousser EF10 et vérifier la CI distante ;
- vérifier l'intégration Zenodo avant publication ;
- créer, vérifier puis pousser le tag annoté v2.0.0 ;
- créer la release GitHub avec RELEASE_NOTES_v2.0.0.md, sans pré-release ;
- vérifier Zenodo, relever les DOI effectivement attribués, puis créer un
  commit documentaire post-release ;
- ne jamais déplacer un tag publié.

## English

EF10 prepares version v2.0.0, metadata, the stable facade, compile-time
contract, permanent guard, changelog, notes, scope documentation, build,
axiom audit, and a clean tree. Manual steps are to push EF10, verify remote
CI and Zenodo integration, create and verify the annotated v2.0.0 tag, publish
the GitHub release using the notes, verify Zenodo, record assigned DOIs in a
later documentation commit, and never move a published tag.
